## Motivation

I was motivated to learn about Web Scraping using Playwright and to learn GraphQL by using MongoDB.

## Features

- Upload a recipe from a url
- View saved recipes
- View a recipe

## How to run

Run the following command: `docker compose up` and navigate to http://localhost:5173/
