## Motivation

I was motivated to practice React with TypeScript for the front end and to learn GraphQL and Web Scraping.

## Features

- Create/Read/Update/Delete a recipe
- Scrape a recipe from a url

## What I've learned

- web scraping
- graphql

## What I've used

- web scraping
- graphql
- React
- TypeScript
- react-hook-form
- zod validation

## How to run

Run the following command: `docker compose up` and navigate to http://localhost:5173/
